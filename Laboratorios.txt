========================================
Hands-on Lab 1: Database bootstrap
========================================
Tasks:
- Start SQL Server container.
- Run schema script.
- Run seed script.
- Validate categories/products.

Acceptance:
- Students can query seed products and explain constraints.


========================================
Hands-on Lab 2: Product CRUD vertical slice
========================================
Tasks:
- Create entity + DTOs.
- Build repository + mapper.
- Implement service.
- Expose controller.
- Test in Swagger.

Acceptance:
- Product can be created, searched, updated, and deactivated.


========================================
Hands-on Lab 3: Inventory replenishment and adjustment
========================================
Tasks:
- Implement InventoryService.
- Write movement rows for every mutation.
- Block invalid adjustment type.
- Block adjustment out beyond stock.

Acceptance:
- Stock changes and movement history prove the mutation.


========================================
Hands-on Lab 4: POS sale flow
========================================
Tasks:
- Post a multi-item sale.
- Validate product status.
- Validate stock.
- Calculate subtotals and total.
- Persist sale and movements.

Acceptance:
- Sale is created and inventory is reduced for every item.
